GSE274934 RNA, TCR, and ATAC

Scientific limitations: Exploratory analysis. RNA donors by tumor type: ALK_positive_LUAD n=4, WT_LUAD n=5. Cell-type labels are marker-based and unvalidated. Where doublet status is LOW_CONFIDENCE, Scrublet did not remove the expected doublet rate. RNA and ATAC are separate libraries, so this report does not match an RNA cell to an ATAC cell and does not run WNN, MultiVI, or same-cell peak-to-gene linking. ATAC differential accessibility is not tested unless every tumor type has at least 3 ATAC donors. RNA edgeR, when the design has at least 3 donors in each tumor type, tests donors. Those FDRs are not confirmed cell-type biology. No batch correction is applied. There is no response annotation and no causal claim.

Dataset

GEO GSE274934. RNA samples: AL02, AL03, AL04, AL05, AL06, AL08, AL10, AL11, AL12. QC-retained RNA cells: 97,017. Genes after RNA filtering: 29,287. ATAC is analysed only for samples that have both a peak matrix and a Cell Ranger singlecell file. AL06 has RNA and TCR and no ATAC library.

Downloaded sample source

NCBI GEO GSE274934. Tumor-type labels are the GEO sample characteristic tumor type, copied into the sample sheet.
